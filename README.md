## অ্যাপ ইনস্টল করুন · Install the app

### 📱 Android (মোবাইল) · Android 8.0 and above  <sub>— সবচেয়ে সহজ / easiest</sub>

**বাংলা**
1. উপরের **Android (.apk)** ডাউনলোড করুন — ফাইলটি **Downloads** ফোল্ডারে যাবে।
2. নোটিফিকেশন থেকে ফাইলটিতে চাপুন, অথবা **Files → Downloads → `nid-verify-*.apk`** খুলুন।
3. **Allow from this source** চাইলে সেটিংস থেকে অনুমতি দিন, তারপর ফিরে আসুন।
4. **Install → Open** চাপুন। Play Protect সতর্কতা দেখালে **"Install anyway"** বেছে নিন।
5. অ্যাপে **QR স্ক্যান** চাপুন এবং পাশের কোডটি স্ক্যান করুন — অথবা কোডটি লিখে দিন।

**English**
1. Download **Android (.apk)** above — it lands in your **Downloads**.
2. Tap it from the notification, or open **Files → Downloads → `nid-verify-*.apk`**.
3. If prompted, turn on **Allow from this source** in Settings, then return.
4. Tap **Install → Open**. If Play Protect warns, choose **"Install anyway"**.
5. In the app tap **Scan QR** and scan the code — or type the code in.

### 🖥️ Windows (ডেস্কটপ) · Windows 10/11 (64-bit)

**বাংলা**
1. উপরের **Windows (.exe)** ডাউনলোড করুন।
2. ডাউনলোড শেষে ফাইলটিতে **ডাবল-ক্লিক** করুন।
3. **"Windows protected your PC"** দেখালে **More info → Run anyway** চাপুন।
4. **Next → Install** দিয়ে সেটআপ শেষ করে অ্যাপটি খুলুন।
5. অ্যাপে পাশের **৮-অক্ষরের কোডটি** লিখে দিন — ডেস্কটপে ক্যামেরা না থাকলে এটিই সহজ।

**English**
1. Download **Windows (.exe)** above.
2. **Double-click** the file when the download finishes.
3. If **"Windows protected your PC"** appears, click **More info → Run anyway**.
4. Finish setup with **Next → Install**, then open the app.
5. Type the **8-character code** shown next to it — easiest when the desktop has no camera.

## যেভাবে কাজ করে · How it works

**বাংলা**
1. আপনার ফোন বা কম্পিউটারে **Amarseba NID Verify** অ্যাপটি ইনস্টল করুন।
2. অ্যাপ খুলে পাশের **QR কোডটি স্ক্যান** করুন, অথবা কোডটি লিখুন।
3. নিজের তথ্য দিয়ে নিজে **এনআইডি পোর্টালে লগইন** করুন।
4. সম্পন্ন করুন — যাচাই **স্বয়ংক্রিয়ভাবে** এই পাতায় দেখাবে।

**English**
1. Install **Amarseba NID Verify** on your phone or computer.
2. Open the app and **scan the QR code** shown, or type the code.
3. **Log in to the NID portal yourself** with your own credentials.
4. Finish — your verification appears **automatically**.
